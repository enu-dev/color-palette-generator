# Color Palette Generator — 配色パレット生成ツール

配色理論に基づいてパレットを自動生成するブラウザ完結型ツールです。

**デモ：** `https://enu-dev.github.io/color-palette-generator/`（GitHub Pages公開後に更新）

---

## 機能一覧

### カラー入力
- HEXコード直接入力
- カラーピッカー
- H / S / L スライダー（リアルタイム連動）

### 6種類の配色理論

| タイプ | 内容 | 色数 |
|--------|------|------|
| **補色** (Complementary) | 色相環180°反対。インパクトのあるコントラスト | 2色 |
| **類似色** (Analogous) | 隣接する色相±30/60°。調和の取れた柔らかい配色 | 5色 |
| **トライアド** (Triadic) | 色相環を120°ずつ3等分。バランスの良い鮮やかな配色 | 3色 |
| **スプリット** (Split Complementary) | 補色の±30°。補色より穏やかなコントラスト | 3色 |
| **テトラード** (Tetradic) | 色相環を90°ずつ4等分。豊かで複雑な配色 | 4色 |
| **モノクロ** (Monochromatic) | 同一色相・明度違い5段階。統一感のある配色 | 5色 |

### カラー形式
- **HEX**：`#00d4ff`
- **RGB**：`rgb(0, 212, 255)`
- **HSL**：`hsl(195, 100%, 50%)`

### エクスポート
- **CSS変数としてコピー**：`--color-1: #00d4ff;` 形式
- **JSONとしてコピー**：カラー名・全形式を含む配列

### 保存・履歴
- お気に入り登録（localStorage）
- 操作履歴の自動保存（スライダードラッグ中は900msデバウンス）

### アクセシビリティ
- WCAG 2.1 コントラスト比の自動計算（白・黒背景対応）
- AAA（7:1以上）/ AA（4.5:1以上）/ AA Large（3:1以上）の3段階評価

### その他
- ランダムカラー生成（🎲ボタン）
- チップクリックでクリップボードコピー
- トースト通知（コピー完了・保存完了）

## 使い方

1. `index.html` をブラウザで開く
2. HEX入力・カラーピッカー・スライダーで基準色を選ぶ
3. 配色タイプ（補色/類似色/トライアド等）を選択
4. 生成されたカラーチップをクリックでコピー
5. 必要に応じてCSS変数 or JSON形式でまとめてエクスポート

ビルド不要。サーバー不要。ファイルをダブルクリックするだけで動きます。

## 実装メモ

### 色計算はすべてHSL空間で処理
配色理論の計算はH（色相）の加算のみで完結するため、入力値をHSLに変換してから各ハーモニーを生成し、最終的にHEX/RGBに戻す構成にしています。

### スライダードラッグのパフォーマンス対策
スライダー操作中はlocalStorageへの書き込みを900msデバウンスで抑制しています。チップ描画は即時応答（デバウンスなし）なので、操作のレスポンスは損なわれません。

### ハーモニー切り替え時のアニメーション
配色タイプを切り替えるとき、CSSクラス `fading`（opacity: 0）を付与して120msのフェードアウト後にチップを再描画します。スライダー操作時は即時更新（アニメーションなし）にして操作感を優先しています。

### WCAG コントラスト比
WCAG 2.1の相対輝度計算式に準拠。白（#ffffff）と黒（#000000）それぞれに対するコントラスト比を計算し、テキストとして使用可能かどうかをバッジで表示します。
